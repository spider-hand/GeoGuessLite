- 🧩 **Rich gameplay** - Single Play, Multiplayer and Daily Challenge.

## Tech Stack

- Frontend: Vue
- Backend: AWS Lambda, Firebase Functions
- Authentication: Firebase Authentication
- DB: Firebase Realtime Database, PostgreSQL
- Hosting: Cloudflare
- Infrastructure: SST
- Others: OpenStreetMap, Mapbox, Mapillary
